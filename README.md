# Pantry-Project

A household pantry and shopping management system built as a full‑stack web application.

- **Frontend:** Vue
- **Backend:** FastAPI
- **Database:** PostgreSQL
- **Focus:** Clean, secure API design, solid data modeling, and a friendly, intuitive UX
---

## Overview

Pantry-Project serves a single household with admin and user roles.  
It helps families organize pantry, fridge, and freezer inventory, and future versions aim to reduce food waste through simple analytics.  
The project highlights relational data modeling, cross-table search and filtering, and explicit security considerations as part of the design.
